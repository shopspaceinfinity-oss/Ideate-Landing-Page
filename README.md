# Techfest Ideate Landing Page

A custom responsive landing-page concept for the Techfest IIT Bombay College Ambassador task. This is a standalone creative concept, not the official Techfest website.

## Design direction
**“Ideas Engineer a Brighter Tomorrow.”** A cinematic editorial design with nighttime event photography, refined typography, subtle grain, hand-written accents, aqua highlights, immersive experience cards and responsive layouts.

## Files
- `index.html` — page structure and content
- `style.css` — visual design, layout, responsive styles and animations
- `script.js` — mobile navigation, scroll reveals and teaser dialog

## Run locally
Open `index.html` in a modern browser. Internet is needed for Google Fonts and the Unsplash-hosted photos; the rest of the site is self-contained.
