# Techfest Ideate Landing Page — Pro Edition

A custom responsive landing-page concept for the Techfest IIT Bombay College Ambassador task. This is a standalone creative concept, not the official Techfest website.

## Design direction
**“Ideas Engineer a Brighter Tomorrow.”** A cinematic editorial design with nighttime event photography, refined typography, subtle grain, hand-written accents, aqua highlights, immersive experience cards and responsive layouts.

## Files
- `index.html` — page structure and content
- `style.css` — visual design, layout, responsive styles and animations
- `script.js` — mobile navigation, scroll reveals and teaser dialog

## Run locally
Open `index.html` in a modern browser. Internet is needed for Google Fonts and the Unsplash-hosted photos; the rest of the site is self-contained.

## Publish on GitHub Pages
1. Create a public repository (for example, `techfest-ideate-landing-page`).
2. Upload `index.html`, `style.css`, `script.js`, and this README to the repository root.
3. Open Settings → Pages → Deploy from a branch → select `main` and `/(root)` → Save.
4. Open the generated GitHub Pages URL and test desktop and mobile layouts.

## Demo recording checklist
Record a 30–60 second screen capture showing:
1. The hero layout and call-to-action buttons.
2. Scrolling through the about and experience sections.
3. Clicking “Play the teaser” to show the custom dialog.
4. Mobile responsive menu and card layouts.

Upload the recording to Google Drive and set General access to **Anyone with the link — Viewer**, then submit both the repository URL and Drive recording URL as required by Techfest.

## Notes
- Links for competitions, workshops and official information point to the Techfest website and should be checked before final submission.
- Event statistics are intentionally not invented; the hero uses edition/day/potential counters as design motifs.
- This concept is independent and not endorsed by Techfest.
